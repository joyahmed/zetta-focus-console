# 🔥 Zetta Focus Console — Feature Distinction

## Philosophy

Free = Complete engine (with limits)
Pro = Commitment & precision
Founder = Permanent status

The engine is never crippled.
Free must feel complete, not artificially blocked.
Free gets 1 custom profile to test the system.
Trial gets full Pro experience to sell the upgrade.
Pro adds discipline and depth.

Zetta Focus Console is not a decorative timer.
It is a structured focus system.

---

# 🟢 Free — The Core Focus Engine

Free includes the full timing engine with **1 custom profile**.

### Core Engine

- Work duration configuration
- Break duration configuration
- Session / loop count
- Start / Pause / Stop
- Automatic work → break transitions
- Restore last base configuration

### Custom Profile (Limited)

- Can create **1 custom profile**
- Can edit the custom profile
- Cannot create multiple saved profiles
- Cannot save multiple presets

### Interface

- Dark & Light theme
- One ambience profile
- Volume control
- Minimal distraction-free layout

### Terminal (Basic)

- `help`
- `status`
- `clear`

Free supports serious daily use.
No essential functionality is removed.

# 🔵 Pro — Commitment & Precision Layer

Pro introduces structured discipline and advanced control.

### Strict Mode (v1 — Commitment Mode)

When enabled for a session:

- Pause is disabled
- Manual stop is disabled
- Session duration cannot be edited mid-run
- If the app is force-closed, the session is marked as failed
- Requires explicit confirmation before activation

Strict Mode is optional per session.
It is not enforced globally.

---

### Advanced Engine Controls

- Runtime overrides (modify active session intentionally)
- Advanced session chaining
- Custom session presets
- Extended configuration profiles

---

### Advanced Ambience System

- Multiple ambience profiles
- Engine-aware ambience transitions
- Premium sound packs
- Dynamic focus-state visuals

---

### Developer Mode

- Engine state inspection
- Session diagnostics
- Reset engine command
- Detailed timing metrics

Pro does not add decoration.
It adds discipline and depth.
