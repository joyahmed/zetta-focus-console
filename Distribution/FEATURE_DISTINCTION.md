# 🔥 Zetta Focus Console --- Free vs Pro Feature Distinction

## Philosophy

Free = Complete tool\
Pro = Control and depth

Never cripple the engine.\
Never make Free feel broken.

------------------------------------------------------------------------

## 🟢 Free Features

### Core Engine

-   Work / Break duration
-   Loop count
-   Start / Pause / Stop
-   Restore base timer from last session

### UI

-   Dark & Light theme
-   One ambience profile
-   Volume control

### Terminal (Basic)

-   help
-   status
-   clear

------------------------------------------------------------------------

## 🔵 Pro Features

### Advanced Engine

-   Runtime overrides
-   Strict focus mode
-   Advanced chaining

### Advanced Ambience

-   Multiple ambience profiles
-   Engine-aware visuals
-   Premium ambient sound packs

### Developer Mode

-   Engine state inspection
-   Diagnostics
-   Reset engine
