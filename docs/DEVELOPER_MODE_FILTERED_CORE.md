# Zetta Focus Console

# Developer Mode --- Refined Magnetic Core

------------------------------------------------------------------------

## Purpose

This document defines the FINAL, filtered Developer Mode vision.

No over-engineering. No feature creep. No gimmicks.

Only what makes the app feel:

-   Fast
-   Native
-   Developer-grade
-   Intentional
-   Polished

If it does not strengthen identity, it is removed.

------------------------------------------------------------------------

# Core Identity

Zetta Focus Console is NOT:

-   A productivity analytics tool
-   A Git tracking system
-   A Slack integration platform
-   A bloated feature dashboard

It IS:

A lightweight, terminal-native focus engine for developers.

------------------------------------------------------------------------

# The Only Features That Matter

## 1. Global Hotkeys (Non-Negotiable)

### Required

-   Ctrl + Alt + S → Start / Stop
-   Ctrl + Alt + P → Pause / Resume
-   Ctrl + T → Open Terminal

### Requirements

-   Must work system-wide
-   No delay
-   No flicker
-   No focus stealing

If hotkeys feel unreliable → product feels amateur.

------------------------------------------------------------------------

## 2. System Tray (Invisible Mode)

### Required

-   Closing window → minimize to tray
-   Tray icon reflects state:
    -   Green → Focus running
    -   Blue → Break
    -   Gray → Idle
-   Tray menu:
    -   Start
    -   Pause
    -   Stop
    -   Open Console
    -   Quit

### Requirements

-   Instant response
-   No lag when restoring window
-   Clean icon design (not cluttered)
-   No memory spikes

If tray feels polished → app feels native.

------------------------------------------------------------------------

## 3. Terminal Excellence (The Signature Feature)

Terminal must feel intentional.

### Required

-   Persistent command history
-   Tab completion
-   Short aliases (s, st, r, stop)
-   Clean output formatting
-   Clear status display
-   No UI jitter

Example:

> status

Session: Running Remaining: 18m 42s Mode: Focus Profile: Default

### Rules

-   No cluttered output
-   No unnecessary commands
-   Fast response (instant feedback)

Terminal is the emotional differentiator.

------------------------------------------------------------------------

## 4. Strict Mode (Optional but Powerful)

Minimal implementation:

strict on strict off

Strict Mode Behavior:

-   No stopping early
-   No pausing
-   Full session required

Optional visual cue: Subtle red accent border when strict mode active.

This reinforces discipline identity.

------------------------------------------------------------------------

## 5. Performance Transparency (Dev Mode Only)

Simple command:

system usage

Shows:

-   CPU usage
-   Memory usage
-   App uptime

No dashboards. No graphs. Just clean terminal output.

This builds trust.

------------------------------------------------------------------------

# Explicitly Removed

The following are intentionally excluded:

-   Git integration
-   Project tagging
-   Webhooks
-   Slack/Discord integrations
-   VS Code extension
-   Plugin system
-   Multi-device sync
-   Cloud analytics
-   Local API server
-   Over-detailed analytics dashboards

These dilute identity.

------------------------------------------------------------------------

# Implementation Quality Standards

Developer Mode must feel:

1.  Instant
2.  Reliable
3.  Minimal
4.  Predictable
5.  Lightweight

Performance Targets:

-   Memory \< 80MB
-   CPU idle \< 1%
-   Startup \< 2 seconds
-   No continuous background polling

------------------------------------------------------------------------

# Launch Criteria

Developer Mode V1 is complete when:

-   Global hotkeys work flawlessly
-   Tray feels native
-   Terminal feels smooth and professional
-   Strict mode works cleanly
-   Performance remains lightweight

Nothing more.

------------------------------------------------------------------------
