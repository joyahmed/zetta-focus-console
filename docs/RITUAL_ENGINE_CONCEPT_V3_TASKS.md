# Zetta Focus Console

# Ritual Engine Concept --- V3 (With Minimal Tasks)

------------------------------------------------------------------------

## Core Positioning

Zetta Focus Console is a Developer Ritual Engine.

It is not: - A productivity analytics dashboard - A Git tracking
system - A gamified focus toy

It is: A lightweight, terminal-driven discipline system built for
developers.

------------------------------------------------------------------------

# The Ritual Model

Every session follows a simple structure:

1.  Declare intention
2.  Commit
3.  Complete

No complexity. No productivity theater. Only intentional focus.

------------------------------------------------------------------------

# Minimal Task System (Ritual-Oriented)

Tasks are NOT a todo manager.

They exist only to bind intention to a session.

## Task Structure

Each task contains:

task: { category: "coding" \| "other", title: "string" }

Example:

task: { category: "coding", title: "Zetta Cloud" }

------------------------------------------------------------------------

## Categories

Only two categories:

-   coding
-   other

No tags. No priorities. No due dates. No subtasks.

This prevents scope creep.

------------------------------------------------------------------------

## Terminal Flow

> task set "Zetta Cloud" --category coding start

Session header:

Session: Running\
Category: coding\
Task: Zetta Cloud\
Remaining: 24m 10s

# Strict Mode (Commitment Mode)

strict on

When enabled:

-   No pause
-   No stop
-   Timer must complete
-   Timer ring becomes red gradient
-   Tray icon turns red
-   Terminal accent turns red

Strict Mode represents commitment.

------------------------------------------------------------------------

# System Integration

## Global Hotkeys

-   Ctrl + Alt + S → Start / Stop
-   Ctrl + Alt + P → Pause / Resume
-   Ctrl + T → Open Terminal

Must be instant and reliable.

------------------------------------------------------------------------

## System Tray

-   Close → minimize to tray
-   Tray icon reflects state:
    -   Green → Focus
    -   Blue → Break
    -   Red → Strict Mode
    -   Gray → Idle
-   Tray menu:
    -   Start
    -   Pause
    -   Stop
    -   Open Console
    -   Quit

------------------------------------------------------------------------

## Startup Option

Optional setting:

"Start with Windows"

If enabled:

-   App launches minimized
-   Runs silently in tray
-   Minimal resource usage

Default: OFF

------------------------------------------------------------------------

# Terminal Excellence

Terminal is the signature experience.

Must include:

-   Persistent history
-   Command aliases (s, st, r, stop)
-   Clean output formatting
-   No clutter
-   Instant response

Everything must work without touching the mouse.

------------------------------------------------------------------------

# Performance Discipline

-   Rust backend
-   Tauri shell
-   Memory \< 80MB
-   CPU idle \< 1%
-   Startup \< 2 seconds
-   No background polling loops

The tool must respect the machine.
